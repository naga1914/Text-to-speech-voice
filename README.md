# 🎤 Text To Speech Converter

This **Text To Speech Converter** allows users to convert any text they type into speech. It features a user-friendly interface, language selection, and options to listen and download the speech output.

---

## 🌐 Live Demo

👉 [View Live Demo](https://text-to-speech-voice.vercel.app/)  

---

## 🌟 Features

- 📝 **Text Input**: Write any text in the provided text area.
- 🎧 **Listen Button**: Click to listen to the text-to-speech conversion.
- 💾 **Download Button**: Download the speech as an audio file.
- 🌐 **Language Selection**: Choose from different available languages for the speech.

---

## 💡 Technologies Used

- **HTML5** – Structure and layout of the web page.
- **CSS3** – Styling the page and making it responsive.
- **JavaScript** – Handles the logic for text-to-speech conversion and file download.
- **Font Awesome** – Used for adding icons (play, download).

---

## 🔧 Setup Instructions

1. **Clone the repository**  
   ```bash
   git clone https://github.com/your-username/text-to-speech-converter.git
   cd text-to-speech-converter
   ```

2. **Open in Browser**  
   Open `index.html` in any browser:
   ```bash
   open index.html
   ```
   Or just double-click the `index.html` file to open it.
